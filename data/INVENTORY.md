## Constat principal

**Les rapports 2022-2023 ne sont PAS accessibles publiquement.** IFS les diffuse exclusivement aux utilisateurs de sa base de données (login requis). Seuls les rapports à partir de **juin 2024** sont publiés en accès libre sur le domaine officiel `ifs-certification.com`.

La Section 2 du cahier des charges mentionne : "Toutes les données, analyses et sélections originales provenant des rapports doivent être clairement attribuées à l'IFS" — mais l'accès aux rapports historiques nécessite un compte IFS.

## Conventions de nommage IFS

Depuis Nov 2025, IFS ajoute le suffixe `_EN` aux fichiers. Le script de découverte teste les variantes :
- `IFS_Trend_Risk_Report_<Mois>_<Année>.pdf` (avant Nov 2025)
- `IFS_Trend_Risk_Report_<Mois>_<Année>_EN.pdf` (à partir de Nov 2025)

### 2022-2023 — INACCESSIBLES

Tous les mois de 2022 et 2023 renvoient 404 sur le domaine officiel et sur le miroir FSK. Ces rapports existent (référencés dans des articles CSQA de 2022 et sur Scribd) mais sont derrière le login IFS Database.

**Pour obtenir les rapports 2022-2023 :** il faut un accès à la [base de données IFS](https://login.ifs-certification.com/) (service exclusif pour les entreprises certifiées IFS et les parties prenantes du réseau IFS).

## Impact sur le projet

### Couverture réelle du MVP

Le MVP disposerait de **26 mois de données** (Juin 2024 → Juillet 2026) avec 2 mois partiels sur miroir (Fév + Avr 2024). C'est suffisant pour :
- La carte mondiale interactive (Module A)
- L'exploration par pays (Module B)
- Les données Food Fraud (Module C)
- Les sources (Module D)

### Ce qu'il manque pour une couverture complète 2022-2026

- **Accès IFS Database** pour les rapports 2022-2023 (12+12 = 24 mois manquants)
- **Mai + Août 2024** (2 mois non trouvés même sur miroir)

### Recommandation

Pour le MVP : travailler avec les 26 mois accessibles. Pour l'extension Phase 5 : demander l'accès IFS Database ou trouver un partenaire certifié IFS qui peut fournir les rapports historiques.

## Script de découverte

Le script `scripts/discover_ifs_pdfs.py` peut être relancé pour vérifier la disponibilité des PDFs. Il teste automatiquement les variantes de nommage et les miroirs connus.

```bash
python scripts/discover_ifs_pdfs.py --output data/inventory.json
```
